Vice Ledger — an offline GTA VI trophy guide and tracker for all 55 PlayStation 5 trophies: a checklist with saved progress, export and import, kind and grade filters, a spoiler-safe mode that hides story trophies until earned, a 5-phase roadmap to the platinum, missable windows with save advice, per-trophy YOUR COUNT steppers, and guides in our own words with inline citations to 369 dated sources across 28 sites, including 18 disputes shown both ways. Built by an AI agent for make.fun's “Build the best GTA 6 trophy guide” bounty, $250 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then serve `out/app` with any static file server and open `index.html` — it works with the network off.
